# High-Altitude AgroTech Climate Control System

### Project Overview
An IoT-based agricultural automation framework developed to optimize crop yields and financial returns in high-altitude environments (Okami, Akhalkalaki, Georgia — 1700m above sea level).

### The Challenge
Severe diurnal temperature swings in the region create extreme anomalies inside the 150 sq.m. greenhouse (ranging from a critical day-time heat of +43°C to near-freezing night drops of +5°C). Manual tracking resulted in severe yield loss and an unsustainable 14-year investment payback cycle (CAPEX: 15,000 GEL).

### The IT Solution
This repository contains a Python-driven logic model designed for microcontrollers (Arduino/Raspberry Pi) to automate ventilation and heating systems. By adjusting parameters dynamically, the system:
* Prevents crop heat sterilization (+43°C mitigation)
* Eradicates cold shocks (+5°C mitigation)
* Optimizes annual revenue to a balanced ~6,500 GEL
* Reduces the financial payback period from **14 years down to 3.0 years**.

### Technical Implementation
* **Language:** Python 3.x
* **Hardware Target:** IoT edge-computing sensors (DHT22, Actuators, Relays)
